Un assistant qui fonctionne sur ton ordinateur

Édition du 14 novembre 2026 : Ollama remplace GitHub Models, retiré le 30 juillet 2026. Le guide et le code utilisent désormais cette configuration locale. Statut officiel de l’ancien service.

Ce n’est pas un assistant public hébergé. Le serveur et le modèle tournent sur ton ordinateur. GitHub Pages sert seulement à partager une démo statique d’ELIZA ou une présentation.

Dans le guide

ELIZA, puis Pixel

Les deux projets sont expliqués étape par étape. Le code est fourni dans les annexes et dans le ZIP.

01 · Comprendre

ELIZA et les règles

Un chatbot à règles en Python, qui repère des mots-clés et remplace des pronoms. Les exemples de dialogue sont en anglais.

02 · Construire

Pixel, sur ton ordinateur

Une interface web, Flask et le modèle local llama3.2:1b via Ollama. Pas de jeton d’inférence, pas de service de conversation Quanthevaris.

03 · Personnaliser

Personnaliser Pixel

Modifie les consignes et les informations fournies au modèle. Le guide explique aussi la gestion de l’historique, des erreurs et des données personnelles.
